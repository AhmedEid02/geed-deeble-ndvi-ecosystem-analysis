- Geed_Deeble_NDVI_2000.tif
- Geed_Deeble_NDVI_2008.tif
- Geed_Deeble_NDVI_2016.tif
- Geed_Deeble_NDVI_2024.tif
- Geed_Deeble_NDVI_Change_2000_2024.tif
- Geed_Deeble_NDVI_Class_2000.tif
- Geed_Deeble_NDVI_Class_2008.tif
- Geed_Deeble_NDVI_Class_2016.tif
- Geed_Deeble_NDVI_Class_2024.tif

The scripts in `scripts/gee/` can reproduce these files from Google Earth Engine.
