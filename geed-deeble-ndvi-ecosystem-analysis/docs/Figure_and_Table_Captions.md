## Tables

### Table 1. NDVI descriptive statistics
**Caption:**

**Table 1.** Descriptive statistics of NDVI values for the Geed Deeble Forest Reserve ecosystem during the MAM/Gu season in 2000, 2008, 2016, and 2024.

**Note if needed:**

NDVI values were derived from Landsat Collection 2 Level-2 Surface Reflectance imagery. Mean, minimum, maximum, and standard deviation values were calculated within the Geed Deeble Forest Reserve AOI.

### Table 2. NDVI class area and percentage
**Caption:**

**Table 2.** Area and percentage distribution of NDVI-based vegetation condition classes in the Geed Deeble Forest Reserve ecosystem from 2000 to 2024.

**Note if needed:**

Vegetation classes were derived from NDVI thresholds representing bare/degraded land, very sparse vegetation, sparse vegetation, moderate vegetation, and dense vegetation.
